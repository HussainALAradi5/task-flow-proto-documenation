# Team API (Client)

`src/app/features/team/services/team.ts` wraps `ApiService` for paginated team listing, create, update, delete, invitations, member removal, and paginated team messages. Only the team creator can edit, invite, or remove. The recipient sees a pending count in the header and can accept or decline on the Teams page. Membership and access to that team's active boards are added only after acceptance. Accepted members can read and send chat messages. The chat uses the shared `GenericDragDropComponent` for one image, GIF, PDF, or text attachment per message (500 KB maximum), offers a small emoji picker, and suggests accepted teammates when `@` is typed. Selecting a suggestion adds its ID to the request; the server checks membership and the visible mention. The Teams page offers grid/list views, linked team boards, and per-team leader/member badges. The profile's Admin/Leader/Member badge is a global account role; it does not overwrite team membership. `TeamInvitation`, `TeamMessage`, `TeamChatMember`, and `SendTeamMessageRequest` live in separate interface/DTO files; `InvitationDecision` and `TeamRole` are enums.
